# Personal Web Portfolio

This is my personal web portfolio that I built using HTML, CSS, and JavaScript.
The project is a simple website that displays my personal information, experience, skills, and projects.

## Tech Stack

- HTML
- CSS
- JavaScript

## Features

- Responsive design
- Animations
- Dark mode
- Project
- Anonymous comments
- Contact form

### Responsive design

The website is designed to be responsive and works well on different devices such as desktop, laptop, tablet, and mobile phones.

### Animations

The website uses CSS animations to add some movement and interactivity to the page.
The animations are added to elements such as buttons, links, and icons.

### Dark mode

The website has a built-in dark mode that can be enabled by the user by clicking a toggle button in the top right corner of the page.
The dark mode is achieved by using CSS custom properties and the `:root` selector.
